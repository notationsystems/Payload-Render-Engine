## AUTHORED - the rules that do not come from a register

1. **Measure, do not assert.** Every claim this repository makes about
   itself is checked. A register that says a thing is present must name
   where that was read from, and a check must fail when it is not.
2. **Absence is never zero.** Anything unknown is ABSENT with a reason
   and a remedy. A blank, a zero, or a silent fallback is a defect.
3. **Prove the check bites.** A check is not finished until a planted
   violation makes it fail by name. A check that cannot fail is worse
   than no check, because it reads as coverage.
4. **The renderer is never authoritative.** A derived representation may
   not mutate the state it derives from. Held by `scripts/check-seam.mjs`
   and, from the other end, by GET-only transport.
5. **Scope every claim.** "In this service" and "in the program" are
   different statements. A register that reports only the first will
   tell another team their work does not exist.
6. **One source per fact.** Doctrine that restates code is generated
   from it. These seven documents are generated for that reason.

## AUTHORED - before you add a surface

Identify, in this order: which **product** owns it (`shared/apis.mjs`),
which **plane** it sits in (`shared/planes.mjs`), and which **limb** its
answer carries (`shared/envelope.mjs`). All three are declared before
the code, and the checks hold the code to the declaration.
