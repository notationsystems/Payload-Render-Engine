# Control Plane - the safe visual contract

What a frontend may render from the governance plane, and what it must never invent.

**Scope.** This describes the Payload Render Engine - a read-only
projection over a corpus it does not own. It is not a description of a
deployed Caravan, Tradewind or Landshark service, and nothing here is
evidence that one exists.

**MEASURED** sections are read from the registers when this file is
generated. **AUTHORED** sections are decisions, and live in the
generator so there is still one source.

## AUTHORED - the visual contract

1. **Logical topology only.** The control plane is not geographic. Do
   not add coordinates. A geographic map requires separately authorized
   WGS84 spatial data, and absent that the honest rendering is a graph.
2. **No raw security detail.** Authority is rendered PRESENT or ABSENT,
   never as a value. Host and network topology, resolvers and
   deployment controls never reach the browser.
3. **Verified transitions only.** Show chronological transitions that
   were recorded. Do not synthesize history from a missing snapshot - a
   gap is drawn as a gap.
4. **Proportional affordances.** Read, compare, filter and inspect. No
   control that changes corpus, rights, release or infrastructure state.
5. **A drill-down is a new authorization.** A provenance path may not be
   turned into a raw-data request from an id or digest alone.
6. **An unknown that looks good is still unknown.** State labels and
   limitation badges come before visual treatment.

**`/api/health`**

**`/api/capabilities`**

- LATENCY MEASURED NOW, FROM THIS PROCESS - a figure here is one sample from one vantage point, not a service level
- a probe result is a REACHABILITY fact, never an existence one: a capability that did not answer may exist and be unreachable

**`/api/security/posture`**

- THE POLICY IN FORCE IN THIS PROCESS - not the policy of the deployment, and not a claim about any other instance
- the CLIENT half of the model cannot be answered from here: the CSP that actually arrived and what is actually in browser storage must be observed in the browser
- the refusal journal is a bounded window that states its own `since` - an empty list is an observed zero for that window, never "nothing has ever happened"
- authority is reported PRESENT or ABSENT only; no credential value is ever returned (SEC-013)

**`/api/system/topology`**

**`/api/ecosystem/register`**
