# Caravan API - the first wedge

Inspect a bounded logistics slice: party/site/shipment resolution, movement lineage, changes, and exceptions.

**Scope.** This describes the Payload Render Engine - a read-only
projection over a corpus it does not own. It is not a description of a
deployed Caravan, Tradewind or Landshark service, and nothing here is
evidence that one exists.

**MEASURED** sections are read from the registers when this file is
generated. **AUTHORED** sections are decisions, and live in the
generator so there is still one source.

## AUTHORED - what it is and is not

**Sector:** Logistics · Freight · Cargo · Maritime supply chain.

**Job:** move physical goods. **Not the job:** the price of a commodity; the zoning of a lot.

**Derived from:** the movement half of the physical economy the twin holds: corridors, chokepoints, ports, facilities and the flows over them.

Object classes: `shipment`, `load`, `container`, `voyage`, `party`, `node`, `milestone`.

It refuses:

- inferring a shipment from an observation - an aircraft track is a track, and promoting it to a movement record would invent a consignment nobody shipped
- price - that is Tradewind, and a corridor read that carried a price would be two products in one answer

### Core versus context

A `core` stream is a record of Caravan's own object class. A `context`
stream informs it without being one. The distinction is load-bearing:
an aircraft track is not a shipment, and a wildfire is not a delay. A
view that renders context as core invents a consignment nobody shipped.

## MEASURED - the migration boundary

The spine the three products would share is `organization`, `site`,
`commodity` and `contract`. Measured against the corpus this twin
serves: **site** is a first-class entity, **commodity** exists and is
thin, **organization** is a string field on facilities rather than a
record, and **contract** is a field rather than a type. Until
organization and contract are entities, the cross-product join cannot
be expressed and Caravan is a single-product corpus.
